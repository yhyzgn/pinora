# 计划 065：图形半透明填充

- 状态：已完成
- 负责人：Codex
- 当前任务：`.context/tasks/065_shape_fill_annotations.md`

## 目标

补齐设计文档 4.4 中矩形/圆角矩形/椭圆的填充与透明度基础能力：用户可在既有 Overlay 工具栏或键盘切换后续图形的半透明填充；每个提交对象冻结填充色和 alpha，预览与导出确定一致。实现必须在现有 Overlay 内完成，不创建新窗口、截图、平台菜单或后台任务，持续满足空闲仅 tray 常驻与任务栏/Dock 隔离约束。

## 非目标

- 不实现任意 alpha 滑块、渐变、图案填充、全局样式预设、文本背景、线/箭头/画笔填充、已有对象选择编辑或持久化默认样式。
- 不重做标注数据模型、渲染缓存、截图、贴图、OCR、导出、tray 或 `window_policy`。

## 约束

- 填充只适用于矩形、圆角矩形和椭圆；默认关闭。启用时从当前描边 RGB 派生固定半透明 alpha，提交后保存在对象中，后续颜色或填充开关不改写旧对象。
- 填充必须先渲染、描边后渲染，以保证边界清晰；所有 alpha 合成走既有 `blend_coverage`，不直接覆盖背景像素。
- 草稿预览和最终烧录共用同一填充字段和几何渲染函数；退化草稿不产生填充对象或 revision。
- 填充切换是当前 Overlay 的纯样式状态，不推进标注文档 revision、不改变 `AssetRef` generation、不提交 worker；工具栏状态变化仅重绘必要区域。
- 生产窗口与事件循环边界保持不变：新入口只在现有工具栏/键盘状态机中切换，任何可见窗口仍经 `window_policy`。

## 依赖关系

- 依赖 030 的标注 revision、预览和资产 generation 契约。
- 依赖 061 的 tray-only GUI 会话与建窗源码守卫。
- 依赖 064 的圆角矩形冻结几何和距离场渲染。

## 阶段

1. 扩展三类封闭图形的标注字段和会话样式状态，锁定填充开关/颜色/alpha 的提交语义。
2. 为矩形、圆角矩形和椭圆增加透明填充栅格化，接入预览和最终烧录顺序。
3. 增加工具栏/快捷键选中态和定向回归，执行 workspace 与上下文门禁。

## 检查点

1. 填充关闭时旧像素输出与当前描边行为一致；开启时内部半透明合成存在、描边仍清晰。
2. 提交对象持有的填充色不会随会话颜色、线宽或开关后的变化而改变。
3. 填充开关本身不产生标注事务、导出任务或新窗口；`window_policy` 源码守卫保持通过。

## 计划级风险

- 大面积半透明预览仍在自绘 Overlay 线程完成；离线像素测试不能证明真实 4K/HiDPI 连续拖拽帧时间。
- 固定 alpha 是基础交付，不是设计文档要求的完整透明度控件；alpha 配置需在独立样式任务实现。
- 真实 tray、任务栏/Dock、合成器映射与工具栏读屏语义仍需平台会话验证。
