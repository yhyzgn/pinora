# 计划 037：历史索引接入 PNG 导出闭环

- 状态：已完成
- 负责人：未分配
- 当前任务：`.context/tasks/037_history_export_integration.md`

## 目标

将 034 的历史索引接入现有受监督 PNG 导出任务：仅在目标文件原子发布并通过导出任务门禁后写入历史条目；索引保存失败时回滚本次内存变更，不发布误导性成功日志。

## 非目标

- 不实现历史窗口、托盘历史菜单、再次贴图/再次编辑入口。
- 不在本任务自动删除配额淘汰或 tombstone 文件；文件事务独立于索引写入。
- 不改变复制、OCR、截图、贴图和导出路径的既有结果语义。

## 约束

- 历史候选只能来自 Pinora `runtime.export_dir()` 下的单个 PNG 文件名，不接受外部路径。
- 候选绑定完成导出任务的 `AssetRef`、owner 和图像元数据；陈旧/关闭/失败任务不得入历史。
- 历史写入失败只记录稳定摘要，不记录图片像素、OCR 全文或绝对路径。

## 阶段

1. 在桌面壳启动时只读加载历史索引，损坏文件保留并使用空内存索引。
2. 为 SavePng 任务保留轻量历史候选；完成后生成条目并原子保存索引。
3. 覆盖成功、失败、历史写入失败回滚和受管文件名边界测试。

## 依赖关系

- 依赖 026/027 的 `ExportJobService` 完成门禁和 034 的 `HistoryStore`。
- 依赖 035 的 `history_limit` 设置读取；本任务不新增设置字段。

## 检查点

- 启动不自动修复或覆盖损坏历史文件。
- PNG 导出完成且文件可读后才写历史；复制文本/图像任务不产生历史条目。
- `HistoryIndex::insert` 后 `HistoryStore::save` 失败时恢复插入前索引。

## 计划级风险

- 历史索引仍未执行文件删除事务；tombstone 可能暂时保留旧文件，需要后续清理任务。
- 启动加载只建立内存索引，不验证每个文件存在性；历史 UI 需另行展示失效条目。

## 完成标准

- 导出完成事件与历史写入有离线契约测试；workspace 质量门禁通过，未覆盖真实桌面路径明确记录。
