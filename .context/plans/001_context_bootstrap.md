# 计划 001：上下文初始化与遗留稳定化

- 状态：已完成
- 负责人：未分配
- 当前任务：`.context/tasks/001_context_bootstrap.md`

## 目标

在修改生产代码前建立长期有效、由证据支撑的上下文体系。

## 非目标

- 初始化上下文期间不重构生产代码。
- 完成语义核对和人工审查前不删除遗留上下文。

## 约束

- 保留人工编写的说明和现有项目行为。
- 不把未经验证的假设写入稳定系统事实。

## 依赖关系

```text
仓库扫描 → 遗留核对 → 特征化任务 → 增量变更
```

## 阶段

1. 扫描仓库并记录经过验证的技术、模块、运行方式和测试事实。
2. 迁移或保留现有说明和记忆前先完成分类。
3. 针对最高风险契约建立最小安全特征化任务。
4. 完成审查和验证后，才开始增量修改生产代码。

## 检查点

- 修改生产代码前审查扫描证据。
- 删除前审查每一项遗留来源的处置结果。

## 计划级风险

- 外部测试或启动命令可能连接共享基础设施。
- 机械迁移可能丢失人工维护的上下文。

## 完成标准

- 入口规则和当前工作指针明确且唯一。
- 系统事实、规范和风险都附带文件或命令证据。
- 当前任务可执行、可测试、可回滚。
- 未覆盖任何人工编写的说明。
