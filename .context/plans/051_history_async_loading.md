# 计划 051：历史图像异步加载与陈旧结果隔离

- 状态：已完成
- 负责人：Codex
- 当前任务：`.context/tasks/051_history_async_loading.md`

## 目标

把历史预览、重新贴图和再次编辑所需的受管 PNG 读取、摘要校验与解码移出桌面事件循环。用户切换条目、关闭历史窗口或重新发起操作时，旧加载任务必须取消或被拒绝，不能卡住窗口、回写错误条目或重新打开已关闭的窗口。

## 非目标

- 不修改历史索引格式、受管 PNG 格式、tombstone 清理、配额、搜索、删除或导出语义。
- 不改变 049 已定义的再次编辑目标、Overlay 呈现方式或帧缓存暂停规则。
- 不以线程测试声称已经完成慢盘、HiDPI、读屏或真实桌面性能验收。

## 依赖关系

- 依赖 021 的 `JobSupervisor`、023/026 的受监督 worker 模式和 042/049 的历史文件完整性校验与再次编辑流程。
- 依赖 050 的辅助窗口策略；新服务不创建任何窗口。

## 约束

- `load_history_image` 的常规文件、长度、摘要、PNG RGBA8、像素尺寸和元数据校验必须完整保留，并在 worker 内执行。
- 结果交付必须绑定历史条目的不可变 `ImageId`/generation、请求意图和当前选择；选择变化、窗口关闭和应用退出时不能回写陈旧结果。
- worker 不得持有 `Window`、`Context`、`Surface`、托盘或剪贴板对象；主事件循环是唯一可创建 Pin/Overlay 或更新面板的线程。
- 正常轮询只能回收已结束 worker；退出沿用有界取消与等待语义。

## 阶段

1. 建立历史读取任务的领域身份、可注入 runner 和离线取消/陈旧结果契约测试。
2. 让历史窗口显式呈现加载中，`desktop_shell` 将预览、贴图和编辑动作提交到服务并在主线程交付。
3. 在选择变化、关闭、删除、清空、截图切换和退出路径取消加载，运行质量门禁并记录未覆盖的真实桌面风险。

## 检查点

- 打开历史窗口、选择条目与搜索输入不会在事件回调内调用 `load_history_image`。
- 只有当前选择且仍打开的历史窗口可得到预览，`Reopen`/`Edit` 只由相匹配的 worker 结果继续执行。
- 加载失败保留历史窗口并显示稳定错误状态；编辑失败恢复帧缓存；被取消或陈旧的结果不显示为错误。
- 历史窗口关闭或应用退出后，加载 worker 被取消并按既有有界等待规则收敛。

## 计划级风险

- 文件系统读取和 PNG 解码本身不能完全抢占；本计划保证它们不阻塞 UI 线程，并以身份门禁丢弃取消后抵达的结果，不承诺强制中断任意底层文件系统调用。
- 新增历史任务身份会扩大 `JobOwner`/`JobKind` 的穷尽匹配面；所有引用须在同一任务内更新并由严格 Clippy 覆盖。
- 离线 worker 测试不能测量真实慢盘、窗口绘制或输入延迟；这些保留为后续桌面性能探针。

## 完成标准

- 历史加载的磁盘读取、摘要验证和 PNG 解码不在桌面事件循环执行。
- 预览、重新贴图和再次编辑均有 owner/条目身份/意图门禁，陈旧或取消结果不改变 UI。
- 相关服务和 shell 契约测试、workspace 严格门禁与 ctx validate 通过；真实慢盘和 GUI 性能验收缺口如实记录。

## 完成记录

- 2026-08-02：新增 `JobOwner::History(ImageId)` 和 `JobKind::HistoryLoad`，历史读取服务以条目的不可变 image/generation 为门禁身份；不改变历史索引或 PNG 数据形状。
- `HistoryLoadJobService` 只允许一个实际读取 worker，磁盘读取、长度/摘要验证和 PNG 解码均在 worker 内执行；快速切换时先取消旧任务、只保留最新请求，取消 worker 尚未收敛前不会再启动并发大图解码。
- 历史预览、重新贴图和再次编辑均在主线程仅消费与当前选中条目、owner 和 job ID 匹配的完成结果；关闭窗口、选择/搜索切换、删除、清空、配额清理、截图切换和退出都会取消未交付请求。
- 历史面板增加加载中状态；加载失败保留窗口和稳定错误，取消/陈旧结果不显示为失败。历史编辑继续只在 worker 成功后暂停帧缓存，Overlay 打开失败仍立即恢复。
- 本地通过历史加载服务 7 项契约测试、历史面板/历史导出/Desktop shell 定向测试、fmt、workspace check、严格 Clippy、全量 workspace 测试（app 131 通过、2 个真实桌面测试忽略；core 55 通过）。真实慢盘、窗口绘制、HiDPI、可访问性和跨平台 GUI 探针尚未运行；预览 XRGB 转换和编辑 `PreparedPreview` 像素准备仍在主线程，留作独立渲染性能任务。
