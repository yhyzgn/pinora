# 计划 013：标注工具增强

- 状态：已完成
- 负责人：未分配
- 当前任务：`.context/tasks/013_annotate_tools_plus.md`

## 目标

在现有矩形/箭头/画笔基础上补齐椭圆、马赛克、文本、颜色循环与线宽调节。

## 交付

1. `pinora-core`：Ellipse / Mosaic / Text + 颜色调色板 + stroke±
2. `desktop_shell`：快捷键 1–6、C、+/-、文本 IME/键入
3. 系统字体栅格化文本（优先 CJK TTF）

## 非目标

- OCR、完整 GUI 工具条、真 alpha 窗口透明

## 约束

- 选区与标注坐标保持像素语义，渲染缩放不得改变领域数据。
- 缺少可解析字体时必须降级或报告，不得崩溃。

## 依赖关系

- 依赖 `.context/tasks/012_annotate_tray_pin_controls.md` 的标注基础与贴图交互。

## 阶段

1. 扩展标注工具和样式状态。
2. 接入 Overlay 快捷键和 IME 文本输入。
3. 增加纯逻辑/渲染回归测试。

## 检查点

- 每个新增工具至少有提交、撤销或像素输出验证。
- CJK 字体路径只作为运行时探测，不能当作通用平台能力。

## 计划级风险

- 手工栅格化的性能、字体覆盖和高 DPI 精度会成为后续重构风险。

## 完成标准

- 椭圆、马赛克、文本、颜色和线宽能力已按当期任务记录，并保留非目标边界。

## 键位

| 键 | 动作 |
| --- | --- |
| 1 / R | 矩形 |
| 2 / A | 箭头 |
| 3 / P | 画笔 |
| 4 / E | 椭圆 |
| 5 / M | 马赛克 |
| 6 / T | 文本 |
| C | 循环颜色 |
| + / = | 线宽 + |
| - | 线宽 - |
| Ctrl+Z | 撤销 |
| Enter | 提交文本草稿，否则烧录贴图 |
| Esc | 取消草稿，否则跳过标注贴图 |
