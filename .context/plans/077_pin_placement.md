# 计划 077：贴图默认避让截图来源

- 状态：已完成
- 负责人：Codex
- 当前任务：`.context/tasks/077_pin_placement.md`

## 目标

让从当前截图 Overlay 新建的贴图默认避开用户刚选取的源区域：在当前已知捕获范围内按右、左、下、上优先级寻找完整容纳且不重叠的物理像素位置。无法避让时采用确定性的受控回退。行为只改变既有贴图窗口的初始坐标，不创建窗口、事件循环、后台任务或展示路径；Pinora 空闲仍只驻留系统 tray，所有辅助窗口继续禁止任务栏、Dock 和分页器入口。

## 非目标

- 不实现贴图之间的碰撞规避、瀑布排列、自动吸附、动画、点击穿透、分组/标签、跨进程位置恢复或新的窗口类型。
- 不改变历史重新贴图的既有坐标语义，不假设历史来源显示器仍存在。
- 不改变截图、标注、OCR、导出、tray、窗口创建/可见性策略、领域持久化形状或公共命令接口。

## 约束

- 位置选择必须是无窗口、无事件循环、无平台句柄的纯逻辑，使用物理像素并避免 `i32` 边界溢出。
- 只有当前 Overlay 的完整捕获范围可作为可用边界；窗口截图或无法提供额外桌面边界的场景不得伪造屏幕拓扑。
- 候选位置必须完整落在可用范围内且与源区域不相交；候选不足时回退到范围内确定性位置，不生成越界坐标。
- 只在普通截图的 `OverlayFinish::Pin` 路径使用该策略；贴图编辑、历史重新贴图、关闭撤销与手动拖动/缩放不受影响。
- 所有窗口继续只能经 `window_policy::create_auxiliary_window` 隐藏创建，并只由 `show_auxiliary_window` 展示；禁止策略模块外建窗、事件循环和显式显示调用。

## 依赖关系

- 依赖 061 的 tray-only 窗口边界和 066 的辅助窗口隐藏创建、唯一展示策略。
- 依赖 076 的 `pin_layout` 纯贴图几何边界与既有缩放/缓存交互契约。

## 阶段

1. 在 `pin_layout` 建立候选位置、完整容纳、不相交与退回规则，并覆盖边界/负坐标/大图回归。
2. 在普通 Overlay 贴图动作中传入当前完整捕获范围，应用纯位置策略；编辑与历史路径显式保持原语义。
3. 执行定向与全量离线门禁，更新上下文和风险登记。

## 检查点

1. 有空间时初始贴图完全避开源区域且保持在当前已知捕获范围；右、左、下、上优先级确定。
2. 没有完整候选时不产生窗口外坐标、不发生循环尝试或创建额外窗口；全屏等不可避让场景稳定回退。
3. 历史、贴图编辑、关闭撤销、滚轮/边缘缩放、OCR、tray-only 与 `window_policy` 守卫保持既有行为。

## 计划级风险

- 无边框窗口的最终位置仍受 Windows、macOS、X11、KDE Wayland 合成器限制；离线算法不能证明真实映射、任务栏/Dock/分页器和焦点。
- 窗口截图的完整显示器 bounds 未保存在当前 Overlay 模型中；本任务只能使用可验证的捕获范围，不能猜测额外屏幕空间。
- 大于可用范围的图像无法同时满足完整容纳与不重叠；必须明确稳定回退而非隐式缩放或截断。

## 完成标准

- 普通截图新贴图在有空间时避开源区域并完整位于当前已知捕获范围；无空间时稳定回退且不越界。
- 不新增窗口、事件循环、显示调用、截图、worker 或系统菜单；空闲 Pinora 只在 tray 常驻，辅助窗口禁止任务栏、Dock 和分页器入口。
- 定向测试、fmt、workspace check、严格 Clippy、全量离线测试、差异检查与 `ctx validate` 通过；原生 GUI 验收缺口如实保留。
