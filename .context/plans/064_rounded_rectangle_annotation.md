# 计划 064：圆角矩形标注

- 状态：已完成
- 负责人：Codex
- 当前任务：`.context/tasks/064_rounded_rectangle_annotation.md`

## 目标

补齐设计文档 4.4 的圆角矩形工具：在现有 Overlay 中通过一次有效拖拽创建可撤销的圆角描边，使用图像物理像素坐标和确定性抗锯齿渲染。圆角参数在提交时冻结到标注对象，预览和导出结果一致；实现不创建新窗口、不重捕获、不增加后台任务，也不改变仅 tray 常驻的窗口边界。

## 非目标

- 不实现填充、透明度、任意圆角半径面板、选择/编辑已有标注、矩形控制点、模糊或文本框重构。
- 不改变矩形、椭圆、直线、箭头、贴图、OCR、导出、截图后端或 `window_policy` 平台策略。

## 约束

- 圆角矩形必须以 `a`/`b` 的物理像素坐标和提交时半径保存；半径从当前线宽确定性派生并钳制到矩形短边的一半，之后改变线宽不得重绘旧标注。
- 有效拖拽才推进 revision；短边、反向拖拽、越界坐标和草稿取消必须与既有图形工具保持受控语义。
- 预览与最终烧录必须调用同一圆角矩形栅格化实现，不能在鼠标移动时重新截图、同步编码整图或创建 UI。
- 工具栏和快捷键仅切换现有 Overlay 的工具状态；生产源码继续只允许 `window_policy` 构造事件循环和直接窗口。

## 依赖关系

- 依赖 030 的标注文档 revision、草稿和资产 generation 约束。
- 依赖 061 的 tray-only GUI 入口和窗口策略源码守卫。
- 依赖 062/063 的可换行工具栏、工具切换和几何标注接入模式。

## 阶段

1. 在核心模型、会话和渲染路径中加入冻结圆角半径的圆角矩形。
2. 接入 Overlay 工具栏与键盘，复用现有拖拽、预览缓存和撤销/重做流程。
3. 添加几何、像素、工具栏及窗口策略回归测试，运行严格门禁和上下文校验。

## 检查点

1. 反向端点、紧凑边界和过大半径仍输出裁剪安全的圆角描边，不访问像素缓冲外部。
2. 预览与已提交对象同用提交半径，旧对象不受会话线宽以后变化影响。
3. 工具入口不新增任务、窗口、事件循环、截图或平台菜单；空闲进程仍只有 tray、热键、IPC 和帧缓存。

## 计划级风险

- 自绘圆角的边缘在 HiDPI、各平台软缓冲与不同颜色背景上的视觉质量尚无原生会话证据。
- 该任务只冻结由线宽派生的半径，不代表设计中完整的可配置填充/透明度/半径样式系统已经交付。
- 源码守卫只能锁定建窗路径，不能证明 Windows 任务栏、macOS Dock、X11/KDE Wayland 合成器的最终显示行为。

## 完成标准

- 圆角矩形可以从工具栏或键盘选择，单次有效拖拽提交且进入既有撤销/重做事务。
- 提交对象保存冻结的圆角半径，预览与最终合成均以同一抗锯齿几何渲染；退化输入不污染文档。
- 没有新增窗口、事件循环、平台菜单、截图或后台任务路径，tray-only 守卫持续通过。
- 定向测试、fmt、workspace check、严格 Clippy、全量离线测试、diff 检查和 `ctx validate` 通过；真实 GUI、HiDPI、任务栏/Dock 与性能缺口明确保留。
