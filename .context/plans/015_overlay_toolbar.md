# 计划 015：选区 Overlay 工具栏

- 状态：已完成
- 负责人：未分配
- 当前任务：`.context/tasks/015_overlay_toolbar.md`

## 目标

对齐 Snipaste 交互：拖出选区后，**在 Enter 离开 Overlay 之前**就在遮罩层显示工具栏；复制、贴图、标注、OCR 均在 Overlay 上完成。

## 交互（目标）

1. 拖拽出选区 → 松手后若有效 → 显示工具栏（选区下方/上方）
2. 工具栏：复制 / 贴图 / 保存 / OCR / 标注工具（矩形…文本）
3. **双击**选区 → 复制截图并关闭 Overlay
4. **中键** → 贴图并关闭
5. **Enter** → 烧录标注后贴图
6. **Esc** → 取消
7. 在选区内拖拽 → 当前标注工具；在选区外拖拽 → 重新框选

## 非目标

- 选区四角缩放手柄（后续）
- 完整 GUI 图标资源
- 移除旧独立标注窗代码的彻底清理（可暂留作兼容）

## 约束

- 保留已有截图、贴图与导出行为，Overlay 工具栏不能阻塞取消或重新截图。
- 选区、工具栏和标注必须在同一坐标系中命中与绘制。

## 依赖关系

- 依赖 `.context/tasks/014_ocr_pin.md` 的本地 OCR 和贴图基础。

## 阶段

1. 引入 `Selecting | Ready` 状态与工具栏布局。
2. 在 Overlay 上接入复制、贴图、保存、OCR 和基础标注。
3. 验证双击、中键、Enter、Esc 和重新框选行为。

## 检查点

- 所有工具栏动作须有可观察结果和不阻塞主事件循环的验证。
- 旧独立窗口路径只在迁移期保留，不作为新增功能的默认入口。

## 计划级风险

- 统一事件循环、帧缓冲和手工命中测试容易产生性能与交互回归。
- 多显示器/高 DPI 和真实桌面截图未由自动化覆盖。

## 完成标准

- 当期工具栏状态、核心动作和基础标注流程按任务记录交付；未覆盖风险已保留。
