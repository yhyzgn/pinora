# 计划 015：选区 Overlay 工具栏

## 目标

对齐 Snipaste 交互：拖出选区后，**在 Enter 离开 Overlay 之前**就在遮罩层显示工具栏；复制、贴图、标注、OCR 均在 Overlay 上完成。

## 交互（目标）

1. 拖拽出选区 → 松手后若有效 → 显示工具栏（选区下方/上方）
2. 工具栏：复制 / 贴图 / 保存 / OCR / 标注工具（矩形…文本）
3. **双击**选区 → 复制截图并关闭 Overlay
4. **中键** → 贴图并关闭
5. **Enter** → 烧录标注后贴图
6. **Esc** → 取消
7. 在选区内拖拽 → 当前标注工具；在选区外拖拽 → 重新框选

## 非目标

- 选区四角缩放手柄（后续）
- 完整 GUI 图标资源
- 移除旧独立标注窗代码的彻底清理（可暂留作兼容）

## 交付

- Overlay 阶段状态 `Selecting | Ready`
- 工具栏布局/命中/绘制
- 动作：Copy / Pin / Save / OCR
- 选区内标注预览烧录
