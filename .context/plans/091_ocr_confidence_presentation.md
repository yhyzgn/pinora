# 计划 091：OCR 置信度阈值与词框呈现

- 状态：已完成
- 负责人：Codex
- 当前任务：`.context/tasks/091_ocr_confidence_presentation.md`

## 目标

将设计文档已定义的 OCR 置信度阈值落实为可持久化设置，并在既有贴图的 OCR 词框层中明确区分低置信词。阈值只影响可视化状态：原始 OCR 结果、全文复制、框选复制、任务缓存和 OCR 执行语义保持完整不变。

## 非目标

- 不更换 Tesseract、语言模型、超时、缓存键、并发模型或 OCR 任务生命周期。
- 不删除、过滤、重排或重写任意 OCR 词、全文、坐标、置信值或剪贴板文本。
- 不新增窗口、事件循环、线程、平台 API、截图路径、网络请求或依赖。
- 不实现尚未收敛的模型目录、OCR 超时配置、导出格式、导出质量、密度或真实原生桌面验收。

## 依赖关系

- 依赖 082 的 `OcrLanguage` 与 schema v2 迁移机制。
- 依赖 088 的 schema v4 原子保存、回读和运行时设置提交顺序。
- 依赖既有 `OcrWord.confidence`、`PinWin.ocr` 和贴图词框绘制路径。
- 依赖 066/061 的 `window_policy` 边界；本任务只重绘既有贴图。

## 约束

- schema v5 在末尾追加单字节 `ocr_confidence_threshold`，默认 `60`，可用范围为 `0..=100`；v1-v4 读取全部以默认值迁移，保存必须继续原子回读。
- 仅当词的置信度为有限且 `0..=100` 内的已知值，并严格小于当前阈值时，才标记为低置信；Tesseract 的 `-1` 未知值、NaN、无穷和越界值不伪造为低置信。
- 词框开启时：选中词沿用既有选中样式；未选中的低置信词采用独立告警描边；其他词保留普通描边。阈值为 `0` 时不标记任何词，`100` 时标记所有已知且小于 100 的词。
- 保存失败不得更改运行时阈值或已打开贴图的渲染；保存成功才应用设置并请求既有贴图重绘，不重跑 OCR。
- 设置、tray、日志和诊断不得输出 OCR 文本、词框坐标、置信度明细或文件路径。

## 阶段

1. 扩展核心设置模型与 repair 规则，锁定阈值分类的纯函数和边界测试。
2. 将设置 codec 升级为 v5，覆盖 v1-v4 默认迁移、v5 往返、非法值修复与原子回读。
3. 扩展现有设置面板，保存成功后传播到运行时；从既有 `PinWin.ocr` 派生词框视觉状态并重绘，不改变 OCR 数据。
4. 运行定向、workspace、跨 target、严格静态、差异和上下文门禁；原生窗口和视觉流畅度仅记录为待验收风险。

## 检查点

1. 默认 60%、0%、100%、边界相等、未知和非有限置信度的低置信判定固定且不修改 `OcrWord`。
2. v1-v4 均可读取为当前 schema 和默认阈值；v5 保存再读回完全一致；保存失败保持旧运行时值。
3. 已有 OCR 词框的低置信状态随成功保存立即在下一次重绘可见，选择和复制仍包含全部相交词。
4. 没有新增可见窗口、后台任务或敏感输出；既有 tray-only 窗口策略守卫继续通过。

## 计划级风险

- 低置信描边在 4K/HiDPI、不同主题和合成器下的可辨性及连续重绘帧时间需要真实桌面会话验证；离线像素/状态测试不能替代该证据。
- Tesseract 的置信度定义随模型、语言和版本变化；阈值仅表达相对视觉提示，不得包装为文本正确性保证。

## 完成标准

- 用户可在设置中将 OCR 阈值调至 0..=100 并可靠保存；旧设置可无损迁移。
- 低置信词框可辨但不删除或妨碍选择、全文/框选复制和缓存复用。
- 保存成功才影响运行时与既有贴图绘制；失败不出现半应用状态。
- 定向、workspace、跨 target、严格静态、差异和 `ctx validate` 通过；真实桌面视觉/性能和任务栏/Dock/分页器证据明确保留为风险。
