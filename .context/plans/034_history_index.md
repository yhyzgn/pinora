# 计划 034：历史索引与安全复用边界

- 状态：已完成
- 负责人：未分配
- 当前任务：`.context/tasks/034_history_index.md`

## 目标

为设计文档的“历史记录与复用”建立可独立验证的领域索引和本地原子存储边界。索引只引用 Pinora 管理目录内的相对文件名，不接管用户主动选择的外部文件；删除先记录 tombstone，文件操作完成后再压缩索引。

## 非目标

- 不实现历史窗口、托盘历史菜单或 GUI 预览。
- 不在本任务中接管已有用户目录中的任意文件。
- 不引入数据库、网络、第三方序列化依赖或共享基础设施。
- 不把单元测试称为真实桌面历史复用验证。

## 约束

- 领域层不得依赖 UI、窗口、环境变量或文件句柄；应用层只接收调用方明确提供的本地索引路径。
- codec 必须拒绝未知 schema、越界长度、非法 UTF-8、绝对路径和路径穿越；损坏索引不得静默覆盖。
- tombstone 是文件操作前的事实记录；只有调用方确认文件处理完成后才允许 compact。

## 依赖关系

- 依赖 033 的版本化设置和原子文件写入原则、017 的 Rust 静态质量门禁。
- 不依赖数据库、网络、真实桌面会话或外部服务。

## 检查点

- core 可独立计算稳定 SHA-256 摘要并执行去重、配额和 tombstone 状态转移。
- app codec 对 magic、schema、保留字段、长度、CRC 和记录字段逐项验证。
- 原子保存后重新读取并逐字段比较；失败时保留旧索引。

## 阶段

1. 定义历史条目、内容摘要、OCR 状态、配额裁剪和 tombstone 事务模型。
2. 实现带 magic/schema/长度校验的索引 codec 与同目录原子保存。
3. 覆盖重复、删除、损坏保留原文件、未知版本和配额裁剪的离线测试。

## 退出标准

- 索引拒绝未知 schema、超长记录、非法 UTF-8 和越界条目，不静默覆盖损坏文件。
- 新增条目按内容摘要去重；删除先生成 tombstone，压缩只移除已标记条目。
- 保存使用同目录临时文件、`sync_all`、rename 和读取校验。
- `cargo fmt`、workspace check、严格 Clippy、定向测试、workspace 测试和 ctx validate 全部通过。

## 计划级风险

- 历史索引只保存受管相对文件名，不负责删除 PNG；若调用方不执行文件事务，tombstone 会暂时积累。
- SHA-256 摘要用于本地去重和一致性校验，不替代文件系统权限或加密存储。

## 风险与回滚

- 风险：手写变长 codec 漏检长度。缓解：字段上限、总长度上限、逐条边界检查和损坏输入测试。
- 风险：文件删除失败造成索引/文件分叉。缓解：索引先 tombstone，调用方完成文件操作后再 compact；本任务不执行文件删除。
- 回滚：移除 `history` 领域与 `history_store` 应用模块，不触及现有截图、贴图和导出契约。

## 完成标准

- 计划目标和非目标在源码、测试与上下文记录中保持一致；未接入 UI 或真实桌面路径的能力明确标为后续工作。
