# 计划 033：版本化本地设置存储

- 状态：已完成
- 负责人：未分配
- 当前任务：`.context/tasks/033_versioned_settings_store.md`

## 目标

建立不依赖 UI 或真实桌面的版本化设置领域模型与原子本地文件存储，使后续主题、贴图、历史和导出设置有可校验、可迁移、损坏可恢复的持久化边界。

## 非目标

- 不实现设置窗口、热键重注册、开机启动、历史索引或用户目录选择器。
- 不引入数据库、网络同步、外部服务或第三方序列化依赖。
- 不将测试文件路径或本地单元测试称为跨平台运行证据。

## 约束

- 设置值与编码/文件 I/O 分层；领域层不得依赖环境变量、窗口或文件句柄。
- 存储格式必须有魔数、schema 版本、长度边界和完整读取验证；未知版本或损坏文件不得被静默覆盖。
- 保存使用同目录临时文件、`sync_all`、rename 和读取校验；失败清理仅限本次临时文件。
- 值校验应逐字段回退到默认值并产生不含敏感路径的诊断摘要。

## 阶段

1. 定义可验证的设置模型、版本号、默认值和字段校验。
2. 实现长度受限二进制 codec 与原子存储，覆盖缺失、损坏、未知版本、保存和覆盖。
3. 建立应用入口的显式加载边界，缺失使用默认值、损坏保留原文件并记录可恢复状态。

## 依赖关系

- 依赖 028 的同目录临时文件、同步、rename 和读取验证原则。
- 依赖 017 的严格 Rust 静态质量门禁。
- 不依赖外部序列化库、数据库、网络服务或真实桌面会话。

## 检查点

- core 设置模型可独立校验并逐字段修复数值；schema 与枚举值由 codec 严格拒绝。
- codec 仅接受精确长度、正确 magic 和当前 schema；未知或损坏内容不触发保存。
- 原子保存后重新读取并验证；启动只读失败状态，不自动写入默认文件。

## 计划级风险

- 固定长度 schema 需要后续版本迁移任务，当前只允许拒绝未知版本，不能假装兼容。
- Linux XDG/HOME 路径只作为当前实验读取策略，不能外推为 Windows/macOS 配置目录支持。
- 设置持久化基础不能被称为完整设置功能；035 已将贴图数量上限和新贴图默认不透明度接入运行时，设置 UI 与主题渲染仍未交付。

## 完成标准

- 设置模型及文件格式有纯离线测试；损坏或未知版本不覆盖原文件。
- 保存路径原子发布并经读取校验；严格质量门禁通过。
- 设置 UI、热键重注册、历史与跨平台目录策略的后续边界明确记录。
