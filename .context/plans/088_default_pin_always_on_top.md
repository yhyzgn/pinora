# 计划 088：贴图默认置顶设置

- 状态：已完成
- 负责人：Codex
- 当前任务：`.context/tasks/088_default_pin_always_on_top.md`

## 目标

将设计文档已定义但尚未落地的贴图默认置顶偏好实现为版本化本地设置。用户可在现有设置面板切换该偏好；原子保存成功后，后续新建贴图按偏好以普通层级或置顶层级创建，现有贴图保持不变。

## 非目标

- 不修改已存在贴图的层级、不批量重排窗口、不改变用户在贴图菜单中手动切换的 `always_on_top` 状态。
- 不实现点击穿透、置顶能力探测、平台权限绕过、窗口新建路径、任务栏/Dock/分页器策略、托盘、截图、OCR、历史或主题扩展。
- 不将 Windows target 编译或离线窗口属性断言称为真实平台置顶验收。

## 依赖关系

- 依赖当前 v3 `AppSettings`、`SettingsStore` 原子写入/读取校验，以及设置窗口的草稿与成功提交语义。
- 依赖 `desktop_shell` 现有新贴图呈现参数和 `window_policy` 唯一建窗边界。

## 约束

- schema 升级到 v4；v1/v2/v3 文件必须以保持既有字段、默认“置顶”的方式迁移，避免改变升级用户已有新贴图行为。
- 二元偏好使用明确 ON/OFF 控件与键盘左右切换，不借用数值加减的歧义表达。
- 只有 `SettingsStore::save` 成功且回读相等后才更新进程内新贴图默认值；保存失败、热键重绑失败和取消均保留旧默认值。
- 空闲态仍只能保留 tray、热键、IPC 与帧缓存；不得新增窗口、事件循环、线程、进程、网络或依赖。

## 阶段

1. 扩展领域设置、修复记录和 v1-v4 codec，锁定默认值、损坏字段和迁移语义。
2. 在设置面板增加明确二元控制，调整固定画布高度且保持所有行、保存/取消按钮不重叠。
3. 仅在成功保存后把默认值接入新贴图窗口的创建层级，覆盖普通/置顶创建和现有贴图不变的纯逻辑契约。
4. 执行定向、workspace、跨 target、严格静态、差异和上下文门禁。

## 检查点

1. v4 可原子 round-trip；v1/v2/v3 迁移后 `default_pin_always_on_top == true`。v4 的该字段仅接受 `0` 或 `1`，其他字节严格拒绝、保留源文件并走既有无效设置降级，且不丢失既有字段。
2. 设置面板能通过鼠标、方向键和取消恢复切换该值；布局不重叠，浅/深主题帧仍受 087 token 控制。
3. 保存成功后新贴图遵循新值；保存失败和已有贴图不改变层级或状态。
4. 不增加窗口或展示入口；`window_policy` 源码守卫、tray-only 和业务回归保持通过。

## 计划级风险

- winit 的普通/置顶窗口层级只表示请求，真实窗口管理器可能限制或延迟生效；必须保留原生桌面验收风险。
- 设置 schema 是持久化形状变更；迁移或 codec 错误会造成用户配置不可读。通过固定长度、严格 schema、逐版本迁移和回读验证控制。

## 完成标准

- 版本化设置和面板可编辑、持久化并读取默认置顶值。
- 后续新贴图且仅后续新贴图遵循已经成功保存的偏好。
- 兼容迁移、定向、workspace、跨 target、严格静态、差异与 ctx 验证通过；真实窗口管理器行为明确保留为风险。
