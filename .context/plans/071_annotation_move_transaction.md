# 计划 071：标注移动事务与实时预览

- 状态：已完成
- 负责人：Codex
- 当前任务：`.context/tasks/071_annotation_move_transaction.md`

## 目标

在 070 的单对象选择基础上落实 P0 编辑手势：按住选中标注拖动，或用方向键以 1 像素、Shift+方向键以 10 像素移动；一次有效拖动或一次方向键操作只生成一个可撤销/重做事务。拖动预览必须只叠加在既有 Overlay 呈现帧，不提前改变文档、revision、导出、贴图或 OCR 输入；释放时才提交原对象到新对象的替换事务。Pinora 空闲继续仅驻留 tray，所有辅助窗口不得出现在任务栏、Dock 或分页器。

## 非目标

- 不实现对象缩放、旋转、锚点拖拽、样式编辑、文本换行/尺寸编辑、多选、对齐/吸附、图层排序、跨文档复制粘贴或持久化编辑历史。
- 不改截图、贴图、OCR、导出、历史、窗口工厂、系统菜单、平台适配器或后台任务。

## 约束

- 移动保留结构化 `Annotation` 的所有视觉参数，仅平移几何坐标；允许几何超出当前画布，呈现时裁剪但不偷偷改变原始几何。
- `AnnotationDoc` 替换事务必须保存原索引、旧对象和新对象；undo/redo 原位替换，新增/清空/删除既有事务顺序和 redo 分支不回归。
- 拖动开始后仅渲染瞬态替换预览；未移动、取消、选择失效、重选或 Overlay 关闭不推进 revision。有效释放才使 asset generation 与已提交层缓存失效。
- 方向键在有选中标注时优先移动标注；无选中标注继续沿用既有 Overlay 选区移动语义。
- 不创建窗口、事件循环、系统菜单、截图或 worker；Overlay、贴图、历史和设置继续仅经 `window_policy` 隐藏创建和展示。

## 依赖关系

- 依赖 030/032/069/070 的 revision、事务、清空、选择和删除契约。
- 依赖 068 的提交层缓存与草稿/提交像素一致性。
- 依赖 061/066 的 tray-only 生命周期和辅助窗口策略。

## 阶段

1. 核心增加对象平移和原位替换事务，覆盖各标注类型、undo/redo 和边界坐标。
2. Overlay 增加选中拖拽与瞬态替换预览；方向键优先移动选中对象。
3. 覆盖预览隔离、资产/revision、缓存、窗口策略与全量离线门禁，更新稳定事实和风险。

## 检查点

1. 一次拖动只在释放时产生一次 revision；取消/零位移不产生事务，预览与最终提交保持一致。
2. 方向键移动保持 1/10 像素步长、撤销/重做和原绘制顺序；删除/清空/新增交错保持事务正确。
3. 移动只在现有 Overlay 内呈现，不生成任务栏/Dock/分页器项、窗口、系统菜单、截图或后台任务。

## 计划级风险

- 瞬态替换预览若使用已提交图层作为像素源，会使马赛克/模糊读取错误；必须始终使用不可变原始裁剪，并与提交后的像素比较。
- 高 DPI 下拖拽映射和选择框可能出现偏移；离线坐标映射只能覆盖模型，真实四类桌面会话仍要验收。
- 静态窗口策略不能观察原生任务栏/Dock/分页器状态，tray-only 约束不能以 CI 替代。

## 完成标准

- 选中标注可拖动或以方向键移动，一次操作一个事务，预览不污染导出或任务输入。
- 平移、删除、清空、新增、undo/redo 维持确定性绘制顺序、revision 和 redo 分支。
- 定向测试、fmt、workspace check、严格 Clippy、全量离线测试、差异检查和 `ctx validate` 通过；真实桌面、HiDPI、帧时间、tray 与任务栏/Dock/分页器风险明确保留。

## 完成记录

- `AnnotationDoc` 已增加私有 `Replace` 事务，保存索引、旧对象与新对象；有效替换推进 revision 并清除 redo，undo/redo 原位恢复。相同对象和无效索引不改变 revision 或 redo 分支。
- 所有 `Annotation` 类型都可在不改变视觉字段的前提下平移；坐标使用饱和加法，允许对象越出当前画布并由呈现层裁剪。
- Overlay 的选择工具可从命中点开始拖动对象，移动中仅以瞬态替换预览合成；释放时才创建一次 `Replace` 事务。Esc、切换工具、重选、提交其他草稿、undo/redo、删除和清空都会取消该瞬态状态。
- 有选中对象时，方向键移动对象，Shift+方向键移动 10 像素；无选中对象仍移动选区。拖拽映射允许光标落到选区外，从而支持将对象拖出画布。
- 已验证：核心平移/事务、替换预览像素、Overlay 映射和步长、窗口策略，以及 `cargo fmt --check`、`cargo check --workspace`、`cargo clippy --workspace --all-targets -- -D warnings`、`PINORA_NO_SYSTEM_CLIPBOARD=1 cargo test --workspace`、`git diff --check` 和 `ctx validate` 均通过。全量离线结果为 app 176 通过、2 忽略，core 81 通过。
- 未验证：真实 Windows、macOS、X11、KDE Wayland 下的高 DPI 拖拽映射、连续移动帧时间、焦点以及所有辅助窗口绝不进入任务栏、Dock 或分页器的窗口管理器结果。
