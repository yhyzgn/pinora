# 项目上下文

`.context/` 保存长期有效且经过验证的项目事实、约束、计划和可执行任务，不保存聊天记录。

## 阅读顺序

1. `AGENTS.md`：入口规则和当前工作指针。
2. `.context/README.md`：文档职责和生命周期。
3. 相关 `.context/system/` 文件：稳定事实、规范和风险。
4. 当前计划：阶段目标、依赖关系和退出标准。
5. 当前任务：一个边界明确、可验证的变更。
6. 源码、测试和命令输出：事实证据。

## 目录职责

- `system/`：跨任务稳定的事实和约束。
- `plans/`：阶段级顺序和退出标准。
- `tasks/`：包含范围、验证和回滚的一项可执行工作。

## 遗留迁移门禁

存在 `.context/migration-state.json` 时，先运行 `audit-migration`。内容单元覆盖率、来源哈希、分类目标、完整内容和唯一来源标记全部通过后，才可执行 `finalize --apply`。未完成迁移会使 `validate` 失败。

禁止创建空的 `decisions/`、`handoffs/` 或 `archive/` 目录；只有存在真实材料时才创建。
